# GlobalBadges

**Install URL:** <https://xmimiez.github.io/SnowPlugins/mime.globalbadges/manifest.json>

Profile badges from EquiBadges (all client mods) and ObaWorkshop BadgeVault, shown in the profile badge row and on Discord's badges page.

Based on GlobalBadges by domi.btnr and Wolfie.

## Network

- `badges.equicord.org`: the badge list for all users, and one user's badges when their profile opens.
- `plugins.obamabot.me`: one user's BadgeVault badges when their profile opens.
