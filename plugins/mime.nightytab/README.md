# Nighty Tab

Opens your Nighty web panel inside Discord: an entry in Discord's settings, an optional button in the profile bar, and a "Download Script" action on messages that replies with your Nighty prefix.

## Network

- The Nighty address you enter in the plugin's settings (HTTP or HTTPS): the page, its scripts and styles, and the requests the page makes to that same address.
- The custom icon address, if you set one.
- Discord's API, to send the "Download Script" reply.
