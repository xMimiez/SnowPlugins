# Pin DMs

Per-account DM categories in the DM list, with colors, custom or most-recent ordering, and collapsible sections. Tap a category name to collapse it, hold it to edit it, and hold and drag it to reorder. Hold a DM and tap Pin DMs to pin it.

A mobile port of Equicord's PinDMs by Vendicated and Aria.

## Network

This plugin contacts no hosts.
