# Channel Spoilers

**Install URL:** <https://xmimiez.github.io/SnowPlugins/mime.channelspoilers/manifest.json>

Covers images, GIFs, and videos in channels you list, on this device only, until you tap them. Only the newest 50 messages are covered, and each message is covered once: reopening the chat does not cover it again. Add a channel by its ID in the plugin's settings.

## Network

This plugin contacts no hosts.
